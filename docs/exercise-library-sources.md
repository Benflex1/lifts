# Exercise Library Source Registry

This registry records the sources and transformations for the delivered exercise-library foundation. It covers the 876 bundled records, the reviewed metadata updates, the single vendored open asset, and the runtime-derived form references. It does not grant rights to excluded upstream images, videos, or animations.

## Current catalog link state

The default catalog contains no populated curated `instructionUrl` values. Its form-reference button therefore resolves to the deterministic YouTube search fallback described in the registry. Optional validated website and direct YouTube links are supported for future/catalog-provided records, but no such third-party media is bundled by this release.

## Exclusions

The repository includes structured exercise data only from the recorded dataset source, one verified Workout Guide illustration, and Lifts-authored generated SVGs. Upstream exercise image files and exercise videos are intentionally not included; their presence in an upstream repository does not establish redistribution rights for Lifts.
