# Exercise Library Source Registry

This registry records the sources and transformations for the delivered exercise-library foundation. It covers the 876 bundled records, the reviewed metadata updates, the single vendored open asset, and the runtime-derived form references. Upstream photographs are loaded at runtime from the public-domain source; they are not vendored or animated by this release.

## Current catalog link state

The default catalog contains a pinned source `instructionUrl` for every bundled record. Valid direct curated website and YouTube links remain highest priority; missing or invalid bundled links resolve to the pinned source guide, while custom exercises retain the deterministic YouTube search fallback.

## Exclusions

The repository includes structured exercise data only from the recorded dataset source, one verified Workout Guide illustration, and Lifts-authored generated SVGs. Upstream photographs are not downloaded or bundled; the app references the pinned public-domain source images at runtime. Exercise videos and animations are not included.
