It covers the 876 bundled records, the reviewed metadata updates, the single vendored open asset, and the runtime-derived form references. Upstream photographs are loaded at runtime from the public-domain source; they are not vendored or animated by this release.

## Current catalog link state

Catalog version 4 provides direct MuscleWiki `/exercise/<slug>` links for six explicitly mapped bundled IDs only; it does not claim a MuscleWiki mapping for every exercise. Free Exercise DB GitHub URLs are internal dataset and image provenance only, not user-facing guide links. During native and web synchronization, catalog v4 replaces legacy bundled GitHub guide URLs while preserving custom links. Valid custom website and direct YouTube links remain highest priority; unmapped IDs and rejected guide links without an applicable mapping use the deterministic YouTube form-search fallback.

## Exclusions

The repository includes structured exercise data only from the recorded dataset source, one verified Workout Guide illustration, and Lifts-authored generated SVGs. Upstream photographs are not downloaded or bundled; the app references the pinned public-domain source images at runtime. Exercise videos and animations are not included.
